# Abductive Hunt

Convert observations into 3-5 mutually discriminating hypotheses. For each, name the cheapest real observation that would be different if it were false. Run probes before selecting a cause.

Emit hypotheses, predicted observations, probe receipts, and the surviving uncertainty. Do not use this for a known mechanical fix or turn evocative language into evidence.
