# Adversarial Press

Draw the trust graph: claimant, selector, witness, executor, scorer, and beneficiary. Collapse nodes controlled by one actor. Search first for circular evidence, retrospective test choice, unfalsifiable ceilings, and irreversible downside.

Emit the smallest counterexample, the compromised edge, and a repair that changes who can cheat. A harsher description without a runnable falsifier is not an attack.
