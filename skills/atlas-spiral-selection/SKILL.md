# Spiral Selection

Map candidates by subsystem, capability, beneficiary, and measurable loss removed. Prefer the vector with the largest witnessed capability gain per new maintenance surface. Freeze before-state, execute one bounded mutation, then measure the same surface.

Seal only distinct improvements with exact evidence and a falsifier. Repetition, aesthetic novelty, or more code without changed behavior is not a spiral.
