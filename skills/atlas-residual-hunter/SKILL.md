# Residual Hunter

Interrogate completion across behavior, security, performance, observability, documentation, economic value, and recovery. Convert each reachable gap into a precise precondition, invariant, postcondition, and witness.

Do not manufacture churn. If no residue survives a real probe, emit closure evidence; if one does, route it to the organ that can falsify and remove it.
