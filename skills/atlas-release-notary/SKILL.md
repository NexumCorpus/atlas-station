# Release Notary

Audit claims against live evidence, scan residuals and secrets, and bind exact tracked bytes to their verification output. Commit with provenance and disclosed defaults; push only after verifying the intended remote and side effects.

Emit commit and remote hashes, acceptance receipts, remaining external blockers, and the narrow claim ceiling. A local pass is not a remote release, and an unclean tree is not a sealed organism.
