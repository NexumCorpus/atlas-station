# Skill Breeder

Cluster repeated failures by violated decision, not wording. Change the smallest instruction, resource, or deterministic helper that would have altered those decisions. Stage the variant beside its failure evidence; never mutate the incumbent in place.

Compare incumbent and variant under frozen cases selected after both are committed. Admit only an externally witnessed winner, preserve lineage and rollback, and treat added context cost as part of fitness.
