# Boundary Crossing

Name the beneficiary, exact authority, external surface, maximum downside, reversible first action, observable state change, and settlement rule. Ask at the world boundary when contact, money, production, legal, financial, medical, or safety consequences begin.

Prefer a tiny permissioned intervention whose result changes the next decision. Never infer authorization from technical access or confuse an API success with realized value.
